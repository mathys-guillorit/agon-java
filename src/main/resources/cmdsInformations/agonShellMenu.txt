----- Available Commands -----

    agon [OPTIONS]
        -h --help       to show current help
        -V --version    show program version
        -v --verbose    add more verbs into program
        -d --debug      add debug messages
        -q --quit       leave console (or do ctrl+c)

        use example : "agon -h" (else command name are not recognized)

    new [ARGS] : run a new game
    help [CMD] : show Shell help (if no argument) or CMD's help
        example : "help redo" or "help pause"
    quit : quit the game
    load FILE : load a game from a file
    save FILE : save the current game
    pause : stop the passing time in blitz mode
    hint : show an advice to play a turn
    undo [N] : cancel the last turn (or the N lasts)
        example : "undo 6"
    redo [N] : replay the last canceled turn (or the N lasts)
        example : "redo 3"
    show
        board : show the current board state
        history : show game turns history
        time : show time left for each players
        configuration : "explicit"
    set PARAM=VALUE : change current configuration
        example : "set debug=true"
