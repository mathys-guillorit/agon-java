----- Available Commands -----

    agon [OPTIONS] [FILE]
        -h --help             show current help
        -V --version          show program version
        -v --verbose          enable verbose output
        -d --debug            enable debug mode
        -g --gui              launch the graphical interface (GUI)
        -c --contest          launch contest mode (read file and output move)

    use example : "agon -c save.asv" (launches contest mode on the provided file)
    use example : "agon -g save.asv" (launches GUI and loads save.asv)
