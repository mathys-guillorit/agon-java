----- Available Commands -----

    new [ARGS] : run a new game
    help [CMD] : show Shell help (if no argument) or CMD's help
        example : "help" or "help pause"
    quit : quit the program
    load FILE : load a game from a file
    save FILE : save the current game
    pause : stop the passing time in blitz mode
    hint : show an advice to play a turn
    undo [N] : cancel the last turn (or the N lasts)
        example : "undo 6"
    redo [N] : replay the last canceled turn (or the N lasts)
        example : "redo 3"
    show board : show the current game state
    show history : show game turns history
    show time : show time left for each players
    show configuration : "explicit"
    set PARAM=VALUE : change current configuration
        example : "set debug=true"
